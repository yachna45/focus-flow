# FocusFlow 🎯

A simple productivity dashboard built with HTML, CSS, and JavaScript.

## Features

- Add and delete tasks
- Mark tasks as completed
- Automatic task completion counter
- Daily progress percentage
- 25-minute focus timer
- Start, pause, resume, and reset timer
- Light and dark mode
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- setInterval()

## What I Learned

While building FocusFlow, I practiced:

- Selecting HTML elements with JavaScript
- Handling click events
- Creating HTML elements dynamically
- Updating the DOM
- Working with CSS classes
- Creating a countdown timer
- Calculating task progress
- Responsive CSS

## Project Goal

I built FocusFlow as a beginner front-end project to practice JavaScript by creating a functional website instead of only following tutorials.
